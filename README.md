# Lebanon Bekaa Map

Interactive, light-themed map of Bekaa Valley villages in Lebanon.

This project provides a static website that can be deployed directly on GitHub Pages. It includes bilingual Arabic/English support, RTL/LTR layout switching, and interactive village markers.

## Highlights

- Static deployment-ready site in `index.html`
- Arabic/English language toggle for the full interface
- Light and satellite map layers
- Clickable village list synced with map markers
- Re-audited village coordinates for improved placement accuracy

## Project Files

- `index.html`: main production page for GitHub Pages
- `app.py`: original Flask/Folium prototype
- `requirements.txt`: Python dependencies for the prototype

## Local Preview

Open `index.html` in a browser.

## GitHub Pages

1. Push this repository to GitHub.
2. In repository settings, open Pages.
3. Deploy from branch `main` and folder `/ (root)`.
